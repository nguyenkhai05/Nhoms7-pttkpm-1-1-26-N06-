# Ma trận lịch và đặt tại chỗ

Chủ sở hữu backend của cặp issue này. API lịch nhiều sân và đặt tại chỗ; phân quyền lễ tân, khóa ca đồng thời.

Khi triển khai, tạo module, controller, service, DTO và truy xuất dữ liệu trong thư mục này. Chỉ import module vào `app.module.ts` sau khi có chức năng thật. Không nhập mã hoặc schema từ dự án tham khảo.
