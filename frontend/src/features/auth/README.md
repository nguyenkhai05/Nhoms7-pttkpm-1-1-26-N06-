# Đăng ký và đăng nhập

Chủ sở hữu frontend của cặp issue này. LoginPage.tsx, RegisterPage.tsx; AuthForm.tsx đang là giao diện mẫu.

Khi API sẵn sàng, tạo hàm gọi API và các component của tính năng ở đây; trang trong `../../pages/` chỉ ghép giao diện và trạng thái. Bỏ dữ liệu minh họa của trang khi nối dữ liệu thật.
