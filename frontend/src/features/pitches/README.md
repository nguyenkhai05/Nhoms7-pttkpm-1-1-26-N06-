# Tìm sân và xem lịch trống UC1.2

Mã API thật nằm ở `api.ts`; kiểu dữ liệu ở `types.ts`; bộ lọc, thẻ sân, chi tiết và ma trận ca nằm trong `components/`. Hai trang sở hữu là `../../pages/PitchListPage.tsx` và `../../pages/PitchDetailPage.tsx`. API backend tương ứng ở `backend/src/pitch/`. Dữ liệu của UC này không lấy từ `mocks/`.
